## About

Xyra is a desktop-style Linux / VPS dashboard built to make remote file management feel more visual, modern and comfortable.

Instead of jumping between clunky tools, raw file lists and old workflows, Xyra gives you a cleaner space to browse your server, manage files, preview assets and work with remote content in a way that feels much closer to a real desktop environment.

## What Xyra Does

- SSH / SFTP based remote workflow
- Desktop-style remote file browser
- Drag & drop uploads
- Remote file and folder management
- Built-in text/code editor
- Image and asset previews
- Archive handling for formats like `.zip`, `.rar`, `.7z`, `.pk3` and `.iwd`
- Server health snapshot
- Remote file search
- Favorite folders and quick paths
- Desktop-like taskbar, selection and keyboard shortcuts
- Secure local secret storage for server logins
- Custom icon pack support

## Why Xyra Exists

Xyra is made for people who spend a lot of time inside Linux servers, VPS systems, webroots, dumps, configs, assets or project folders and want something that feels more natural than a plain remote file list.

The goal is simple:

- less friction
- cleaner remote workflows
- safer file handling
- and a more desktop-like experience for server content
